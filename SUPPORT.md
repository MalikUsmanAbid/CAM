# Getting help

Start with the [quick start](docs/QUICKSTART.md), [model setup](docs/CLOUD_MODEL_SETUP_ROMAN_URDU.md) and [current limitations](docs/STATUS.md).

Developer contact: [usman234dev@gmail.com](mailto:usman234dev@gmail.com).

For ordinary bugs, use the bug-report template and include your CAM commit/version, Windows version, selected provider (without keys), reproduction steps and sanitized error text. For feature ideas, explain the user problem and acceptance criteria.

Never upload your API keys, database, user workspace, credential store or raw logs. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md). Support is best effort; public availability does not imply a commercial service or SLA.
